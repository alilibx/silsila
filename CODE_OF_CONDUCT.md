# Code of conduct

Wirdak follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good faith, and criticise code and ideas rather than people. Wirdak serves people of
every age and background reading the Quran together, so discussions here stay kind.

## Reporting

Report behaviour that breaks the code of conduct to the maintainer, [@alilibx](https://github.com/alilibx), through a
[private security advisory](https://github.com/alilibx/wirdak/security/advisories/new), which only the maintainer can
read. Reports are kept confidential. The maintainer decides on a response following the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
